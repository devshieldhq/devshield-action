# GitHub Action

DevShield automatically scans every push and pull request to identify reliability risks before production.

## Features

- Repository scanning
- Reliability analysis
- Security scanning
- Performance checks
- AI-powered diagnostics
- GitHub workflow integration

## Usage

```yaml
- uses: devshieldhq/devshield-action@v1
  with:
    api-key: ${{ secrets.DEVSHIELD_API_KEY }}
```
